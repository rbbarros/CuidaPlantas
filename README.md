# CuidaPlantas 🌱

Aplicação web responsiva para descobrir plantas ideais para sua casa e aprender como cuidar delas.

## 🔗 Acesse

[cuidaplantas.netlify.app](https://cuidaplantas.netlify.app)

## 🛠️ Tecnologias

- HTML5, CSS3, JavaScript
- API: Wikimedia Commons

## 📱 Funcionalidades

- Catálogo de plantas com imagens dinâmicas via API
- Informações de rega e cuidados
- Layout responsivo para mobile
